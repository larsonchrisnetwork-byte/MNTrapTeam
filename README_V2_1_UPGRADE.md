# MNTrapTeam 2.1.0 — Event Intelligence

Adds an Event Intelligence tab for any tracked shooter.

Features:
- complete imported event history for the selected target year,
- recent form over a configurable target window,
- performance by club,
- performance by month,
- personal best event scores,
- perfect-event score tracking,
- in-state club and event counts.

Apply:

    & ".\.venv\Scripts\python.exe" .\Apply_v2.1.0.py
    & ".\.venv\Scripts\python.exe" -m pytest -q tests
    .\Run_MNTrapTeam.bat
