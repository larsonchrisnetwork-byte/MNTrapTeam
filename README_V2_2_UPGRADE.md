# MNTrapTeam 2.2.0 — Race Changes

Compares current standings with the latest saved snapshot.

Features:
- rank movement,
- HOA movement,
- entered-team and left-team detection,
- cut-line change,
- new and removed shooter detection,

    & ".\.venv\Scripts\python.exe" .\Apply_v2.2.0.py
    & ".\.venv\Scripts\python.exe" -m pytest -q tests
    .\Run_MNTrapTeam.bat
