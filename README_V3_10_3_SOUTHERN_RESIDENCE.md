# MNTrapTeam 3.10.3

Bulk residence capture for all complete 2026 Southern Zone HAA candidates.

Candidate list is loaded from the latest Southern SOS shootHighGunReport.
Only Minnesota rows with eventsCompleted >= 3 are searched.

The script uses the proven MyATA Search/Buddies pre-selection result button to
capture residence city/state for each exact ATA number.

Output:
    data/connector_downloads/zone_residence/southern_2026_residences.json

No zone qualifications are written yet.
